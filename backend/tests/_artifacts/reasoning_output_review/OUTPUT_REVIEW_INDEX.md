# SHOU reasoning & voice — output review bundle

Generated by `backend/scripts/dev/extract_reasoning_outputs.py` on 2026-05-05.

This bundle is **raw extraction only** — no judgement is applied here. The
intent is to capture real, current backend outputs in a single place so they
can be audited later for whether SHOU is reasoning like an astrologer or
falling back to event-first / renderer-invented / generic copy.

All payloads come from live builders/engines:
- Natal: `app.api.routes.natal_interpretation.interpret_natal_chart_ui` (the
  same code path the mobile client hits).
- Period (life chapter): `app.transit.narrative.life_chapter_detector.detect_active_life_chapter`
  driven by the existing fixtures under `backend/tests/fixtures/life_chapter/`,
  combined with `app.transit.narrative.astrolog_narrative_engine.build_period_story`
  for prose.
- Daily: `app.transit.narrative.daily_humanizer_tr.generate_daily_from_event`
  + `app.transit.narrative.daily_synthesis.build_daily_synthesis`. The period
  context is the real `period_core` from
  `tests/_artifacts/transit_narrative_1996-12-28_07-10_istanbul_2026-03-04.json`.

If a case is missing fields it's flagged in the per-case "Missing fields"
section, not silently filled.

## Cross-case observations (raw, not judgement)

These are patterns that recur across files. They should be reviewed with the
team rather than acted on from this artifact alone:

1. **Period contract is rich; period prose is thin.** Cases 2, 3, 5 all have
   strong, chart-specific `selected_meaning` / `renderer_handoff` /
   `suppressed_readings`, but `period_narrative_prose` falls back to the same
   `track_id=default` template. This is the single biggest signal in the bundle.
2. **`period_voice_policy` and `canonical_period_spine_source` are empty across
   all period cases**, suggesting the LifeChapter→renderer voice handoff is not
   yet wired.
3. **T-square gating works as designed** — no PR-D promotion, debug-only.
4. **Daily ↔ period bridge is connected**, with one minor punctuation/sentence
   join glitch and one generic support sentence.
5. **Natal long-form `core_story` and `core_story_ui` register diverge** for
   the Istanbul sample — worth comparing against more charts to see if this is
   systematic.
