# Natal Canonical Core Golden Corpus

Purpose:

- provide the chart-backed acceptance set for natal ontology and canonical state migration
- keep state expectations stable while renderer and legacy migration work changes around them

Rules:

- state expectations are primary; prose expectations are secondary
- this corpus must eventually contain at least 15 validated charts
- each ontology decision must be backed by corpus evidence before it is marked complete

Current status:

- `manifest.json` seeds the first foundation set using existing local natal artifacts
- expectations are intentionally sparse in PR-1 and will be annotated in later PRs
