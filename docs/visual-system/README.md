# Jovia Visual System Contracts

- `normalized_interpretation_schema.ts`: strict schema for raw payloads, normalized tags, visual tokens, layout hints, and illustration slot inputs.
- `visual_adapter.ts`: deterministic adapter from backend-visible payloads to normalized visual system output.
- `illustration_selector.ts`: illustration asset selection contract with fallback logic.
- `layout_rhythm_adapter.ts`: semantic layout-rhythm decision contract.
- `field_mapping_spec.md`: field-by-field mapping rules and implementation notes.
- `example_outputs.json`: three example payload/result pairs.
